# Discover — бронирование туров

Сайт для поиска и бронирования туров. Проект направлен на создание удобного и привлекательного интерфейса, который помогает пользователям знакомиться с туристическими предложениями и выбирать подходящие варианты для путешествий. Сделан по туториалу

## Как запустить проект локально

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/DariaS300/discover.git
   ```

2. Перейти в папку проекта:
   ```bash
   cd discover
   ```

3. Открыть файл `index.html` в браузере.

## Какие решения приняты и что реализовано

### Структура проекта

Разделила файлы по назначению, чтобы было удобнее работать с проектом:
- `index.html` — основная HTML-страница;
- `Css` — стилизация и оформление сайта;
- `Js` — JavaScript-код;
- `Img` — изображения проекта;
- `favicons` — иконки сайта.

### Визуальное оформление

При разработке уделила внимание внешнему виду сайта и организации контента, чтобы представить туристический сервис в удобном и понятном формате.
